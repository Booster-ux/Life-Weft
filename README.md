# LIFEWEFT — Personal Life-Management & Memory Workspace

Lifeweft is a personal life-management and memory workspace. It is NOT simply a to-do list — Lifeweft helps people manage what they need to do, what they need to remember, what they need to decide, what they need to plan, what they need to learn, what happened in their lives, important deadlines, personal knowledge, and different areas of their lives.

## Core Features

- **Today (Command Center)**: Central hub displaying today's priorities, tasks due today, upcoming deadlines, scheduled activities, recent ledger entries, and quick capture.
- **Personal Ledger**: Chronological timeline journal of significant events across multiple ledgers (Personal, Work, Business, School, Startup Journey, etc.) with support for tags, attachments, and linking to tasks/deadlines/decisions.
- **Life Areas**: Organize your entire life workspace across distinct areas (Personal, Work, Business, School, Family, Projects, or custom areas) without needing multiple accounts.
- **Universal Quick Capture**: Fast, instant capture for Tasks, Ledger Entries, Notes, Deadlines, and Decisions.
- **Ask Lifeweft**: An intelligent conversational interface designed to query your personal workspace data (tasks, deadlines, ledger entries, decisions, and knowledge).
- **Decision Journal**: Structured decision-making logs capturing situations, options with pros/cons/cost/time/risk analysis, chosen paths, and expected vs. actual outcomes.
- **Deadlines**: Time-sensitive milestone tracking with urgency categorization and task linkage.
- **Weekly Planner**: Day and week planning with time blocks for deep work, study, health, and personal focus.
- **Knowledge Base**: Curated repository for notes, links, reference manuals, and ideas.
- **Global Search**: Search instantly across all workspace entities (`Ctrl+K` / `Cmd+K`).

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (with custom calm, dark/deep blue palette and gold accents)
- **Icons**: Lucide React
